# 中国专利《发明内容》章节写作建议（基于 EHFNet）

## 1. 建议章节结构

建议“发明内容”按以下顺序组织，符合中文专利常见表达：

1) **要解决的技术问题**
- 现有分子对接方法在刚体-柔性统一建模方面存在不足：
  - 刚体平移/旋转与扭转角往往分离处理，误差传递链长；
  - 在三维空间中旋转不变/等变约束不充分，导致姿态预测不稳定；
  - 蛋白-配体跨尺度（原子/残基/口袋）信息融合不足；
  - 训练中边数爆炸导致显存不可控，难以工程化落地。

2) **技术方案**
- 提出一种基于 `SE(3) × T^m` 流形的条件流匹配蛋白-配体对接方法；
- 采用“分层异构图编码 + 帧感知卷积 + 等变运动读出”的网络结构；
- 联合输出刚体平移速度、旋转角速度与扭转角速度；
- 采用动态跨图边重建、课程学习、时间感知损失与边预算采样策略。

3) **有益效果**
- 在统一流形上联合优化三自由度，降低模块割裂造成的累计误差；
- 通过体帧投影与帧不变特征提升旋转泛化稳定性；
- 通过动态边重建与覆盖性修复降低“信息断链”风险；
- 通过边预算采样和 OOM 级联熔断提升训练稳定性与可复现性。

4) **可选实施方式提示（在发明内容可简述）**
- 推理积分可选 Euler 或 RK4；
- 可开启/关闭蛋白坐标冻结；
- 可配置课程学习预热轮数与边预算阈值。

## 2. 本项目可主张的关键技术点（建议作为独立权利要求支撑）

### 2.1 面向 `SE(3) × T^m` 的联合速度场学习
- 训练时对配体真实构象与随机初始构象构建插值路径，并分解得到：
  - 分子级平移速度 `v_translation`；
  - 分子级旋转角速度 `v_rotation`；
  - 键级扭转角速度 `v_torsion`。
- 推理时对速度场进行常微分方程积分，逐步更新构象。

### 2.2 分层异构图四阶段编码
- 在每个 GNN block 中按“层内精化→自下而上聚合→层间交互→自上而下广播”进行消息传递；
- 原子层使用 EGNN 更新坐标与特征；
- 非原子层使用 FrameAwareConv 进行 SE(3)-不变的几何消息聚合。

### 2.3 帧感知不变特征与体帧等变读出
- 通过局部帧构造与相对位置投影提取旋转不变几何特征；
- 在主惯量体帧中预测平移/旋转方向，再投影回世界坐标，保证输出等变；
- 平移采用“EGNN 物理先验 + MLP 体帧方向”的门控融合。

### 2.4 动态跨图边重建与覆盖性修复
- 在训练过程中依据当前坐标动态重建 ligand-protein 原子跨图边及 ligand-residue 跨图边；
- 当半径图为空时回退 kNN，确保跨图连接存在；
- 对未覆盖 ligand 原子补充至少一条跨图边，避免局部节点信息中断。

### 2.5 时间感知损失与物理约束协同
- 对平移/旋转采用尺度平衡后的 Huber 损失；
- 对扭转采用周期性余弦损失处理角度同余；
- 对亲和力仅在后期时间步激活监督；
- 位阻惩罚采用 `t^4` 动态加权，抑制后期不合理穿插。

### 2.6 工程化训练稳定机制
- 边预算模式动态批采样控制显存；
- OOM 自适应降批与恢复策略；
- OOM 级联熔断机制避免无效重试。

## 3. “发明内容”可直接改写的参考文本（草案）

### 3.1 要解决的技术问题（示例）
本发明旨在解决现有蛋白-配体分子对接技术中，刚体平移、刚体旋转与内部扭转自由度难以统一建模、跨尺度几何语义融合不足以及训练显存开销不可控等问题，提出一种基于等变分层流匹配网络的分子对接方法与系统，实现对配体结合构象的稳定、高效预测。

### 3.2 技术方案（示例）
为实现上述目的，本发明采用如下技术方案：

A. 构建蛋白-配体异构图，至少包括配体原子节点、配体分子节点、蛋白原子节点、蛋白残基节点和蛋白口袋节点；

B. 基于条件流匹配框架，在 `SE(3) × T^m` 流形上定义从随机初始构象到真实结合构象的连续演化路径，训练网络预测切空间速度场；

C. 采用分层异构图编码器在每个编码块中依次执行：层内精化、自下而上聚合、层间交互和自上而下广播，其中原子层通过 EGNN 更新坐标与特征，非原子层通过帧感知卷积提取旋转不变几何关系；

D. 基于分子主惯量体帧进行等变读出：
- 平移速度由 EGNN 原子位移质心分支与体帧 MLP 分支门控融合得到；
- 旋转速度由体帧角速度方向及幅值读出并投影到世界坐标得到；
- 扭转速度由可旋转键两端原子特征读出得到；

E. 训练时采用动态跨图边重建策略，根据当前坐标重建配体-蛋白跨图边，并在半径邻域为空时采用 kNN 回退及覆盖性修复；

F. 损失函数由平移损失、旋转损失、扭转损失、亲和力损失和位阻惩罚构成，其中亲和力监督在后期时间步激活，位阻惩罚采用时间感知动态权重；

G. 推理阶段通过 ODE 积分器对所述速度场进行数值积分，迭代得到目标结合构象。

### 3.3 有益效果（示例）
与现有技术相比，本发明至少具有以下有益效果：

1) 在统一流形中联合学习刚体与柔性自由度，提升对接构象生成的一致性；

2) 通过帧感知不变特征与体帧等变读出，提高旋转姿态变化下的鲁棒性；

3) 通过动态跨图边重建与覆盖性修复，增强跨分子相互作用信息传递完整性；

4) 通过时间感知损失设计，使模型在不同扩散阶段聚焦不同优化目标，提升收敛稳定性；

5) 通过边预算采样与 OOM 自适应机制，降低训练过程显存波动，提升工程可部署性。

## 4. 写作注意事项（中国专利实务向）

- 尽量使用“本发明提供一种……方法/系统/装置/存储介质”的固定句式；
- 发明内容避免出现过多实验指标，指标可放“具体实施方式”或“实验例”；
- 算法表述建议用“模块 + 步骤 + 输入输出”方式，弱化特定框架名（如 PyTorch）；
- 核心创新点尽量在发明内容中形成“并列条款”，便于后续映射到权利要求 1~N；
- 对可替换实现（如积分器、邻域构图策略）应写“优选地/可选地”，扩展保护范围。
